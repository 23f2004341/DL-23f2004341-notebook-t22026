# Milestone 1 – NLP Foundation & Semantic Similarity

## Objective

The objective of Milestone 1 is to build a strong Natural Language Processing (NLP) baseline for the Smart MCQ Solver Challenge.

This milestone focuses on understanding the dataset, preprocessing textual data, generating semantic representations using classical NLP techniques, and evaluating baseline retrieval performance.

---

## Tasks Completed

* Dataset exploration
* Missing value analysis
* Text preprocessing

  * Lowercasing
  * Removing unwanted characters
  * Tokenization
* TF-IDF Vectorization
* Word2Vec Embedding Generation
* Cosine Similarity based Answer Ranking
* MAP@3 Evaluation
