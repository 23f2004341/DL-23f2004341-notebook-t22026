# Milestone 2 – Transformers & Context-Aware Embeddings

## Objective

The objective of Milestone 2 is to explore Transformer-based Natural Language Processing (NLP) models and understand how contextual embeddings improve semantic understanding compared to classical feature extraction techniques.

This milestone introduces the Hugging Face ecosystem, BERT architecture, attention mechanisms, sentence embeddings, zero-shot classification, and small language models.

---

## Topics Covered

- Hugging Face Datasets Library
- Hugging Face Transformers Library
- BERT Tokenizer
- Special Tokens ([CLS], [SEP], [PAD], [MASK], [UNK])
- Batch Tokenization
- BERT Architecture
- Multi-Head Self-Attention
- CLS Embedding Extraction
- Context-Aware Sentence Embeddings
- Sentence Transformers (MiniLM)
- TF-IDF vs Transformer Embeddings
- Zero-Shot Classification
- Small Language Models (FLAN-T5)

---

## Tasks Completed

- Loaded dataset using Hugging Face Datasets.
- Created combined textual representations using `.map()`.
- Explored tokenizer configuration.
- Learned special token usage.
- Tokenized complete datasets.
- Studied BERT encoder architecture.
- Generated contextual embeddings.
- Compared TF-IDF against Sentence Transformer embeddings.
- Performed zero-shot classification using BART.
- Generated text using FLAN-T5.
